35 Domino: 6-day onboarding course

Over six days you'll learn how this C++ dominoes game works: what it does, how one turn flows through the code, how to trace it in the debugger, and how to change it yourself.

Before Day 1

Set up your computer by following the setup guide, section 4.1 (about 45 minutes).

Each day, open that day's page below, work through it top to bottom, and click Mark this day complete at the end.

The six days

Day 1: The story and the map

By the end of today you have the project running on your Windows machine, you can say in two minutes what the program does, and you can name every class and its job.

about 5½ hours

Day 2: The main flow

Explain, using real class and method names, everything that happens during one turn: from the player typing 5-6 to the points appearing on screen. Then read that code in order, layer by layer.

about 5½–6 hours

Day 3: Trace it live

Watch the real program run the main flow in the debugger. Stop at every layer from the sequence diagram, inspect the data, and step through all three simulator scenarios plus the "pass" path.

about 5 hours

Day 4: Data and integrations

Understand how game data is shaped (model objects vs plain records), how it's saved and loaded, what counts as "config" here, what touches the outside world, and follow one tile through its whole life.

about 5 hours

Day 5: Break and fix

Find and fix three realistic bugs using only the symptoms, the diagrams and the debugger. Practise the loop you'll use every day as a developer: reproduce → locate → understand → fix → verify.

about 5 hours

Day 6: Build and explain

Build a small feature on your own that runs through every layer of the resume flow (file → record → model → control → screen). Then explain the whole program flow back to your mentor on a whiteboard, without notes.

about 5½ hours
